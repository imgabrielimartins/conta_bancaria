# 💳 Conta Bancária em TypeScript

Projeto desenvolvido em **TypeScript** simulando o funcionamento básico de uma conta bancária, aplicando conceitos fundamentais de Programação Orientada a Objetos (POO).

O sistema permite criar contas, realizar depósitos, saques e consultar saldo, com validações e organização estruturada do código.

---

## 🚀 Tecnologias Utilizadas

- **TypeScript**
- **Node.js**
- **ts-node** (para execução em ambiente de desenvolvimento)
- **npm**

---

## 📌 Funcionalidades

- ✅ Criação de conta bancária  
- ✅ Depósito de valores  
- ✅ Saque com validação de saldo  
- ✅ Consulta de saldo  
- ✅ Encapsulamento de atributos  
- ✅ Uso de classes e métodos  

---

## 🧠 Conceitos Aplicados

- Programação Orientada a Objetos (POO)  
- Classes e Objetos  
- Encapsulamento  
- Métodos públicos e privados  
- Tipagem estática com TypeScript  
- Validação de regras de negócio
